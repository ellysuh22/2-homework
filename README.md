# 🎯 나만의 퀴즈 게임

터미널에서 동작하는 Python 콘솔 4지선다 퀴즈 게임입니다.

## 프로젝트 개요

메뉴에서 번호를 선택하면 퀴즈 풀기, 퀴즈 추가, 퀴즈 목록, 퀴즈 삭제, 점수 확인을 할 수 있는
콘솔 프로그램입니다. 외부 라이브러리 없이 파이썬 표준 라이브러리(`json`, `os`, `random`, `datetime`)만 사용했습니다.

추가한 퀴즈와 최고 점수는 `state.json`에 저장되므로, 프로그램을 종료하고 다시 실행해도 그대로 유지됩니다.

## 퀴즈 주제와 선정 이유

**주제: 파이썬 기초 문법**

이번 미션에서 직접 배우고 사용한 개념(리스트, 불린, 생성자 `__init__`, 딕셔너리, 반복문)을
그대로 문제로 만들었습니다. 게임을 만들면서 쓴 문법이 곧 문제가 되기 때문에,
프로그램을 완성하는 과정 자체가 복습이 되도록 주제를 골랐습니다.

## 실행 방법

Python 3.10 이상이 필요합니다.

```bash
git clone https://github.com/ellysuh22/2-homework.git
cd 2-homework
python3 main.py
```

## 기능 목록

| 메뉴 | 기능 | 설명 |
| --- | --- | --- |
| 1 | 퀴즈 풀기 | 몇 문제를 풀지 고르면 그만큼 랜덤 출제하고, 정답/오답을 즉시 알려준 뒤 결과와 점수를 보여줍니다. |
| 2 | 퀴즈 추가 | 문제, 선택지 4개, 정답 번호를 입력받아 새 퀴즈를 등록하고 파일에 저장합니다. |
| 3 | 퀴즈 목록 | 저장된 퀴즈를 번호와 함께 보여줍니다. |
| 4 | 퀴즈 삭제 | 번호를 골라 퀴즈를 삭제하고 파일에 반영합니다. |
| 5 | 점수 확인 | 최고 점수와 최근 게임 기록(날짜/문제 수/정답 수/점수)을 보여줍니다. |
| 6 | 종료 | 프로그램을 종료합니다. |

### 점수 계산

- 점수 = `맞힌 문제 수 ÷ 푼 문제 수 × 100` (100점 만점, 반올림)
- 힌트를 1회 사용할 때마다 5점 차감 (최저 0점)
- 이전 최고 점수보다 높으면 최고 점수를 갱신합니다.

### 보너스 기능

- **랜덤 출제** — `random.sample()`로 매 판 문제 순서를 섞습니다.
- **문제 수 선택** — 시작 전에 몇 문제를 풀지 정할 수 있습니다.
- **힌트** — 정답 입력창에서 `5`를 누르면 힌트를 볼 수 있고, 5점이 차감됩니다.
- **퀴즈 삭제** — 등록된 퀴즈를 지우고 파일에 반영합니다.
- **점수 기록 히스토리** — 모든 게임의 날짜/시간, 푼 문제 수, 정답 수, 점수를 저장합니다.

### 잘못된 입력 처리

- 입력 앞뒤 공백은 제거 후 처리합니다. (` 1 ` → `1`)
- 숫자가 아닌 입력(`abc`), 허용 범위 밖 숫자(`0`, `9`), 빈 입력(그냥 Enter)은
  안내 메시지를 출력하고 다시 입력받습니다.
- `Ctrl+C`(KeyboardInterrupt)나 입력 스트림 종료(EOFError)가 발생해도 비정상 종료하지 않고,
  안내 메시지를 출력한 뒤 데이터를 저장하고 안전하게 종료합니다.
- `state.json`이 없으면 기본 퀴즈 5개로 시작하고, 손상되었으면 안내 후 기본 퀴즈로 복구합니다.

```
2-homework/
```

### 코드 구조

- **`Quiz`** — 퀴즈 한 문제를 표현합니다.
  - 속성: `question`(문제), `choices`(선택지 4개), `answer`(정답 번호 1~4), `hint`(힌트)
  - 메서드: `display()`, `check()`, `to_dict()`, `from_dict()`
- **`QuizGame`** — 게임 전체를 관리합니다.
  - 속성: `quizzes`(퀴즈 목록), `best_score`(최고 점수), `history`(게임 기록)
  - 메서드: `show_menu()`, `run()`, `play_quiz()`, `ask_one()`, `add_quiz()`, `list_quizzes()`,
    `delete_quiz()`, `show_score()`, `record_result()`, `load_state()`, `save_state()`,
    `input_int()`, `input_text()`

## 데이터 파일 설명 (state.json)

- **경로**: 프로젝트 루트 `./state.json` (`main.py`와 같은 위치)
- **인코딩**: UTF-8 (`ensure_ascii=False`로 한글을 그대로 저장)
- **역할**: 퀴즈 목록과 최고 점수, 게임 기록을 저장해 프로그램을 다시 실행해도 유지되게 합니다.
- **생성 시점**: 첫 실행 시에는 없으며, 퀴즈 추가·삭제 또는 게임 종료 시 자동으로 만들어집니다.

### 스키마

```json
{
  "quizzes": [
    {
      "question": "파이썬에서 리스트를 만들 때 사용하는 괄호는?",
      "choices": ["( )", "[ ]", "{ }", "< >"],
      "answer": 2,
      "hint": "순서가 있고 나중에 값을 바꿀 수 있는 자료형에 쓰는 기호입니다."
    }
  ],
  "best_score": 80,
  "history": [
    { "date": "2026-08-04 20:04", "total": 5, "correct": 4, "score": 80 }
  ]
}
```

| 필드 | 타입 | 설명 |
| --- | --- | --- |
| `quizzes` | list | 퀴즈 목록 |
| `quizzes[].question` | str | 문제 |
| `quizzes[].choices` | list[str] | 선택지 4개 |
| `quizzes[].answer` | int | 정답 번호 (1~4) |
| `quizzes[].hint` | str | 힌트 (없으면 빈 문자열) |
| `best_score` | int | 최고 점수 (0~100) |
| `history` | list | 게임 기록 (날짜/시간, 푼 문제 수, 정답 수, 점수) |
